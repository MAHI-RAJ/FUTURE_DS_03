College Event Feedback Analysis (Google Colab)

📌 Overview
This project focuses on analyzing student feedback ratings collected after college events. Using Python and Google Colab, the analysis identifies satisfaction levels, strengths, and improvement areas to enhance future campus events.

🧠 Key Objectives
1-Clean and prepare student feedback data
2-Compute an overall satisfaction score
3-Analyze ratings across multiple feedback criteria
4-Visualize trends and relationships between factors
5-Provide actionable recommendations

🛠 Tools & Technologies
1-Google Colab (Python)
2-pandas – data manipulation
3-matplotlib / seaborn – visualization

📊 Analysis Highlights
1-Overall satisfaction score distribution
2-Average rating per feedback category
3-Correlation heatmap between feedback factors
4-Identification of top strengths and weak areas

🎯 Key Insights
1-Strong performance in clarity and subject knowledge
2-Improvement needed in prerequisite explanation and doubt resolution
3-Data-driven recommendations provided for event improvement
